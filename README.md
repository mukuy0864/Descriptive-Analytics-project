# Descriptive Analytics Project

## Project Overview
This project focuses on Descriptive Analytics using Microsoft Power BI. It analyzes data to understand past performance, identify patterns, and generate meaningful insights through interactive visualizations and dashboards.

## Objectives
- To analyze and summarize data.
- To identify trends and patterns.
- To create meaningful charts and visualizations.
- To present data in an easy-to-understand format.

## Tools and Technologies
- Microsoft Power BI
- Data Visualization
- Data Analysis

## Project Features
- Data analysis and summarization
- Interactive charts and graphs
- Dashboard-based visualization
- Identification of trends and patterns
- Insights to support decision-making

## Project File
The Power BI project file (`.pbix`) is included in this repository.

## Learning Outcomes
- Learned the basics of descriptive analytics.
- Practiced data visualization using Power BI.
- Understood how to present data insights through dashboards.

## Conclusion
This project demonstrates how descriptive analytics and Power BI can be used to summarize data, visualize information, and understand past performance.
